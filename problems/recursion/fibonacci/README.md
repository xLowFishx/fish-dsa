# Fibonacci Number

## Problem

Given a non-negative integer `n`, return the `n`th Fibonacci number.

The Fibonacci sequence starts with:

- `F(0) = 0`
- `F(1) = 1`

For `n >= 2`:

- `F(n) = F(n - 1) + F(n - 2)`

## Expected Function Signature

```js
export default function fibonacci(n) {}
```

## Examples

```text
Input: 0
Output: 0
```

```text
Input: 1
Output: 1
```

```text
Input: 6
Output: 8
```

## Constraints

- `0 <= n <= 45`
- Return a number
